# FCR 검토도우미 — 시연판

현장설계변경(FCR) 변경내역서 엑셀을 올리면 금액 = 수량 × 단가, 합계단가 = 재료비 + 노무비 + 경비, 증감 수량 = 변경 − 당초를
검사하고 틀린 곳의 위치(시트·행·비목)를 보여 주는 한 장짜리 시연 화면입니다.

- 파일은 브라우저 안에서만 읽고 어디에도 보내지 않습니다. AI를 쓰지 않습니다.
- `test_data/`의 엑셀은 모두 시험용 가짜 자료입니다.
- 실제 프로그램(장고, 계산·서류 대조·법령 근거 규칙·의견서 초안)은 내부 PC에서만 돌며, 이 시연판은 계산 검사 일부만 담았습니다.
